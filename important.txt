------How does JS execute code------

--> Javascript Execution Context

      1.Memory Execution Context
      2.Functional Execution Context.

     |--------|  
     |        |
     |   {}   | -> Memory Creation Phase
     |        |
     |--------|

example ->
           let val1 = 10
           let val2 = 5
           function addNum(num1,num2){
            let total = num1 + num2
            return total
           }
           let result1 = addNum(val1,val2)
           let result2 = addNum(10,2);





Step 1- Global Execution (allocate using this keyword)

step 2 - Memory Phase ( muttered all the variables , 
and all the variable are declared with a value of undefined ,and  function which holds definition)
ex- 
     val1 = undefined
     val2 = undefined
     addNum = definition
     result1 = undefined
     result2 = undefined

step 3 - Execution Phase (in which actual values are assign)
ex- 
    val1 -> 10
    val2 -> 5
    addNum -> new variable environment + Execution thread has been created.
   then again Memory and Execution phase occurs for addNum.

   a) Memory Phase -> val1 = undefined
                      val2 = undefined
                      totat = undefined

   b) Execution Phase -> num1 = 10
                         num2 = 5
                         total = 15
                         then total returns in global Execution Context.
   now the new variable environment + Execution thread has been deleted (it is mandatory on obviously ultimately).

   result2 -> again same new variable environment + Execution thread , this process occurs...
